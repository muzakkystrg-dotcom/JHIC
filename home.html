Selamat datang di website resmi SMK Telkom Sidoarjo. Sebagai institusi pendidikan vokasi di bawah naungan Yayasan Pendidikan Telkom, kami bertekad menciptakan lingkungan pembelajaran yang adaptif, kolaboratif, dan berstandar industri masa depan.

Melalui kurikulum berbasis industri dan program sertifikasi kompetensi global, para siswa tidak hanya menguasai keterampilan teknis rekayasa perangkat lunak maupun telekomunikasi, tetapi juga dibekali karakter akhlak mulia dan ketangguhan mental profesional.

Program 4 Tahun

SIJA (Sistem Informasi Jaringan & Aplikasi)

Fokus pada rekayasa perangkat lunak, cloud platform, database architecture, kecerdasan buatan (AI), dan cybersecurity.

Cocok untuk:

  • Tertarik coding, web & mobile app
  • Mempelajari sistem server & cloud
  • Magang industri 1 tahun penuh (Year 4)
Prospek Karir:
Full-Stack Dev Cloud Admin UI/UX Designer
Program 3 Tahun

TJAT (Teknik Jaringan Akses Telekomunikasi)

Fokus pada jaringan transmisi fiber optic, instalasi radio microwave, broadband connectivity, router/switch Cisco & MikroTik.

Cocok untuk:

  • Tertarik instalasi perangkat keras jaringan
  • Ahli kabel fiber optik & telekomunikasi
  • Siap kerja cepat di ISP & Telco provider
Prospek Karir:
Network Engineer Fiber Specialist NOC Engineer
